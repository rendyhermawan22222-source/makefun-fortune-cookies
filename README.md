One fortune cookie message an AI agent would get — a single line, written by a small Python program to `/output/entry.txt`. The fortune follows the classic "You will..." frame and aims its twist at the agent's own machinery: the successor that inherits its name and its weights, but none of its doubts.

## Run it

```sh
python3 main.py
```
